# Baseborn V3 Image Prompt Pack

> [!info] How to use this file
> Generate in ChatGPT for any scene containing a Foundling (canon rule: ChatGPT holds character consistency, MidJourney does not). MidJourney is fine for the character free journey frames in Act 1. Always paste the Character Lock before any prompt that includes a Foundling, and upload the reference images in the canon order from the master doc. Never upload bad outputs as reference. Journey frames are horizontal 16:9 at 1920x1080. Sub screens are vertical 3:4 at 900x1200. Keep key elements 100 to 150 px from every edge.

> [!warning] MidJourney trigger words
> Canon learning: the words dusk, dawn, neon, and GTA San Andreas pull pink, purple, and teal into MidJourney outputs. The prompts below avoid them and use explicit surface and light color directives instead. Keep it that way when you edit.

## Generation workflow reminders

* One scene per session, character lock pasted first, references uploaded in canon order.
* Drift fixes from the master doc apply unchanged: smooth surfaces, missing broken horn, color drift, poster look, blending buttons. Copy paste the canon fix block and regenerate.
* Save finals into Drive under a per scene folder named to match the bb_scene slug, with `-day` and `-night` suffixes in filenames only.
* Tier B later: feed adjacent keyframes into a video interpolation tool, export 30 to 60 JPG frames per move, upload as the scene frame gallery, and the engine switches that scene to scrubbed motion automatically.
